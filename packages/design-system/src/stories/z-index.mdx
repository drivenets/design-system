# Z-index

Portaled overlays stack in tiers. Each tier is a CSS custom property on `:root`, so an app can place its own
overlays between the DS tiers, or move a tier, without reading the compiled CSS.

| Token                | Default | Tier                                    | Read by today    |
| -------------------- | ------- | --------------------------------------- | ---------------- |
| `--z-index-popover`  | `1000`  | Popovers anchored to page content       | `DsPopover`      |
| `--z-index-drawer`   | `1200`  | Drawer panels                           | —                |
| `--z-index-modal`    | `1200`  | Modal and dialog content                | —                |
| `--z-index-dropdown` | `9999`  | Select, autocomplete and dropdown menus | `DsAutocomplete` |
| `--z-index-tooltip`  | `9999`  | Tooltips                                | —                |

Overlays are moving onto these tokens one component at a time. Until a component reads its token, overriding the
token doesn't move that component.

## Placing an app overlay

Read the tokens instead of copying their numbers:

```css
.app-banner {
	z-index: calc(var(--z-index-modal) + 1);
}
```

## Moving a tier

Override the token on `:root`:

```css
:root {
	--z-index-popover: 1100;
}
```
